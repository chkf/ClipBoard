# Clipboard — 产品需求报告

## 1. 产品定位

一款极简的 iOS 原生剪贴板管理工具，通过自定义键盘和主 App 自动收集系统剪贴板内容，使用户能够在不同 App 中快速复用历史复制内容。

| 项目 | 定义 |
| --- | --- |
| 产品名称 | Clipboard |
| 支持平台 | iOS 26+ |
| 分发方式 | IPA 侧载 |
| 目标用户 | 个人使用 |
| UI 框架 | SwiftUI + UIKit |
| 设计语言 | Liquid Glass |
| 数据存储 | 纯本地 |
| 网络依赖 | 无 |

## 2. 设计原则

- 极简优先，不引入非必要功能。
- 自动收集，无须手动保存。
- 键盘负责快速使用，主 App 负责管理。
- 优先使用 iOS 原生组件和公开 API。
- 所有数据在本地处理和存储。
- 不依赖后台保活、越狱或外部服务。

## 3. 功能需求

### 3.1 自动收集

在以下场景自动检查并读取系统剪贴板。

- 主 App 启动或重新进入前台。
- Clipboard 键盘被唤起。
- 主 App 或 Clipboard 键盘处于活动状态期间，检测到剪贴板发生变化。

发现新的有效内容后，自动保存并刷新历史记录，不需要用户主动点击保存。

通过系统剪贴板变化计数与内容匹配判断是否产生新的复制操作，避免重复打开 App 或键盘导致重复记录。

仅在系统允许访问剪贴板时执行收集。

### 3.2 内容类型

| 类型 | 处理方式 |
| --- | --- |
| 文本 | 普通文本、网址、代码等统一作为纯文本处理，保留原始内容及换行。 |
| 图片 | 保存可读取的完整图片，并生成用于列表展示的缩略图。 |

不支持独立文件、音频、视频及富文本格式。

### 3.3 历史记录

- 主 App 与键盘共享同一份历史记录。
- 按最近捕获或复制时间倒序排列。
- 文本按照完整内容精确去重。
- 图片按照统一内容表示的哈希去重。
- 再次复制相同内容时，将已有记录移至顶部，并刷新保留期限。
- 仅重新打开 App 或键盘，不刷新记录时间。
- 不限制历史记录条数。
- 不主动过滤密码、验证码等敏感内容。

### 3.4 自动清理

默认保留最近 30 天的历史记录。支持 7 天、15 天、30 天（默认）和 90 天。

过期记录在下一次主 App 或键盘具备执行条件时自动清理，同时删除关联图片和缩略图。

修改保留期限后立即按照新的规则进行清理。

### 3.5 主 App

主 App 负责历史记录浏览、复制、预览和管理。

| 操作 | 行为 |
| --- | --- |
| 点击文本 | 重新复制完整文本 |
| 点击图片 | 重新复制完整图片 |
| 长按文本 | 预览完整文本 |
| 长按图片 | 预览完整图片 |
| 左滑记录 | 删除单条记录 |
| 点击设置 | 打开设置页 |

重新复制已有内容时，更新对应记录的排序和保留期限，不生成重复记录。

删除历史记录不影响系统当前剪贴板。未发生新的复制操作时，不应重新收集刚刚删除的内容。

### 3.6 Clipboard 键盘

通过 iOS Keyboard Extension 实现。用户可以在支持第三方键盘的 App 中，通过系统键盘切换入口打开 Clipboard。

- 自动检查并收集当前剪贴板。
- 展示共享历史记录。
- 支持纵向滚动。
- 点击文本直接将完整内容插入当前输入框。
- 点击图片将完整图片写入系统剪贴板，由用户执行系统粘贴。
- 支持系统键盘切换。

键盘不提供删除、搜索、收藏、设置和完整内容预览功能。

### 3.7 自动切换键盘

设置中提供「插入后自动切换键盘」开关，默认关闭。

| 开关状态 | 插入文本后的行为 |
| --- | --- |
| 关闭 | 保持 Clipboard 键盘打开。 |
| 开启 | 切换至系统指定的下一个键盘。 |

图片操作仅执行复制，不视为文本插入。

### 3.8 设置

设置页仅包含三项功能。

| 设置项 | 默认值或行为 |
| --- | --- |
| 保留期限 | 30 天 |
| 插入后自动切换键盘 | 关闭 |
| 清空历史记录 | 执行前二次确认 |

清空历史记录时，同时删除关联图片和缓存，但不清除系统当前剪贴板。

## 4. UI / UX 设计

### 4.1 整体风格

- 使用 iOS 原生设计语言。
- 使用系统 Liquid Glass 组件。
- 自动适配深色和浅色模式。
- 使用系统字体、颜色、图标和交互反馈。
- 避免不必要的卡片、标签、装饰及说明文字。
- 不使用 WebView 模拟原生界面。

### 4.2 主 App

采用单页面结构，无底部导航栏。顶部为 Clipboard 标题和设置按钮。

主体为纵向历史记录列表，文本展示摘要，图片展示缩略图。

通过点击、长按和左滑完成主要交互，不为每条记录添加独立操作按钮。

首次使用时，在必要的空状态中提供键盘启用和权限配置指引。完成配置后不再展示。

### 4.3 键盘界面

采用单列纵向列表。

- 文本最多预览两行。
- 图片显示缩略图。
- 不显示时间、类型标签或其他冗余信息。
- 不使用复杂卡片。
- 不提供普通字母键盘。
- 根据系统要求提供键盘切换入口。
- 尽可能保持与系统键盘相近的视觉体验。

### 4.4 设置界面

采用原生 SwiftUI Form。使用系统选择器、Toggle 和破坏性操作样式，不引入自定义设置组件。

## 5. 系统架构

| 逻辑模块 | 职责 |
| --- | --- |
| Clipboard App | 主界面、内容预览、历史记录管理、设置和前台剪贴板收集。 |
| Keyboard Extension | 键盘界面、剪贴板收集、文本插入、图片复制和键盘切换。 |
| Shared Core | 剪贴板读取与变化检测、内容识别及去重、历史记录持久化、图片存储及缩略图管理、过期数据清理、共享设置和跨进程数据一致性。 |

主 App 与键盘通过 App Groups 共享本地数据。

推荐使用 SQLite 管理历史记录元数据，使用共享容器内的文件存储图片及缩略图。具体实现由后续技术设计确定。

## 6. 数据模型

### ClipboardItem

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一标识 |
| `type` | `text` / `image` |
| `text` | 文本内容 |
| `imagePath` | 图片存储路径 |
| `thumbnailPath` | 缩略图路径 |
| `contentHash` | 内容哈希 |
| `createdAt` | 首次捕获时间 |
| `updatedAt` | 最近有效复制或捕获时间 |

### ClipboardSettings

| 字段 | 默认值 |
| --- | --- |
| `retentionDays` | `30` |
| `autoSwitchKeyboard` | `false` |

另外维护用于剪贴板变化检测的共享状态，处理设备重启、进程重启及应用自身写入剪贴板等场景。

## 7. 非功能需求

### 性能

- 键盘打开时优先展示已有历史记录。
- 剪贴板读取不得长时间阻塞界面。
- 图片使用缩略图展示及按需加载。
- 避免一次性加载全部原始图片。
- 控制键盘扩展的内存占用。

### 数据一致性

- 主 App 与键盘共享唯一的数据源。
- 跨进程读写必须保证一致性。
- 删除和过期清理后不得残留无效图片引用。
- 进程意外终止不得导致已有历史记录损坏。

### 隐私

- 不进行网络请求。
- 不接入统计、广告或第三方追踪 SDK。
- 不收集用户在其他 App 中输入的内容。
- 不将剪贴板内容写入调试日志。
- 使用系统提供的数据保护机制。
- 不提供云端同步。

## 8. 明确排除的功能

- 收藏与置顶。
- 搜索与分类。
- 标签与文件夹。
- 历史内容编辑。
- 账号系统。
- iCloud 同步。
- 敏感内容自动过滤。
- 分享扩展。
- 快捷指令集成。
- 手动收集入口。
- 后台持续监听。
- App Store 上架及商业化功能。

## 9. 系统限制与异常处理

- App 与键盘均未处于活动状态时，无法保证捕获剪贴板变化。
- 两次收集之间发生多次复制，可能只能获取最后一次复制的内容。
- 自动读取需要遵循 iOS 剪贴板访问授权。
- 用户拒绝授权时，不影响已有历史记录的使用，并提供必要的权限提示。
- 键盘需要开启完全访问权限，才能正常执行共享数据写入等操作。
- 部分输入框及 App 不支持第三方键盘。
- 图片无法通过通用键盘文本接口直接插入。
- 自动切换键盘无法指定目标输入法。
- IPA 签名必须正确支持主 App、键盘扩展及 App Groups。

## 10. 验收标准

- [ ] IPA 安装后能够正常启用 Clipboard 键盘。
- [ ] 打开主 App 可以自动收集剪贴板。
- [ ] 打开 Clipboard 键盘可以自动收集剪贴板。
- [ ] 文本和图片能够正常保存、展示和复用。
- [ ] 主 App 与键盘历史记录保持一致。
- [ ] 重复复制能够正确去重、置顶和刷新期限。
- [ ] 反复打开 App 或键盘不会产生重复记录。
- [ ] 键盘能够插入完整文本。
- [ ] 键盘能够将历史图片重新复制到系统剪贴板。
- [ ] 自动切换键盘设置正常生效。
- [ ] 主 App 支持完整内容预览、单条删除和清空历史。
- [ ] 过期记录及关联文件能够正确清理。
- [ ] 删除的内容不会因重复读取同一次复制而恢复。
- [ ] 重启 App 后历史记录及设置不会丢失。
- [ ] 无网络连接时所有核心功能正常使用。
- [ ] 界面符合 iOS 原生设计风格。
- [ ] 权限不足、读取失败等异常情况下不会崩溃。

## 11. 交付目标

交付一款功能完整、可独立安装运行的 iOS Clipboard App，包含主 App、Keyboard Extension、共享数据模块及 IPA 构建所需配置。

不引入超出本需求范围的功能。具体技术规范、实施任务及测试方案由后续 OpenSpec 开发流程负责。
